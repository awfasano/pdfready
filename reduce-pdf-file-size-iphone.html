Reduce PDF file size on iPhone

PDFReady has three export modes so you can choose between keeping the PDF as-is and trying for a smaller file, then measures the finished size for you.

Free to download. Your first 3 PDFs are free. Pro is $4.99 once, or a 7-day free trial then $2.99 per year.

How to do it in PDFReady

  1. Add the PDF from Files in PDFReady.
  2. Select the pages to keep. Fewer pages is the simplest way to get a smaller file.
  3. Pick a mode: Original keeps text and annotations; Balanced or Smaller render pages as images to try to reduce size.
  4. Optionally set a size limit (1, 2, 5, 10 or 20 MB, or a custom 0.05 to 100 MB).
  5. Create the PDF, compare the measured size with an original export of the same pages, preview it and share it.

What you can do

  • Try Balanced first, and Smaller if you need more reduction.
  • See the real size of the result, not an estimate.
  • Compare against an original export of the same pages.
  • Keep Original mode when you need text and links intact.

Questions

What is the difference between Balanced and Smaller?

Both render pages as images to try to reduce file size. Smaller favors size over detail. Inspect the preview to confirm it is still readable.

Will text still be searchable?

Not in Balanced or Smaller. Those modes flatten searchable text, links and forms, and PDFReady does not add OCR.

Why did my PDF get bigger?

A small vector PDF can grow after pages are rendered as images. Use Original mode, or select fewer pages.

Can it hit an exact size?

No guarantee. Limits guide compression, and the actual output is measured. A target can be unattainable.
